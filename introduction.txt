Linier independence
linear combination is simply taking a bunch of vectors x1,...,xk
streaching/shrinking each one by a scalar number lambda 1,...,lambda k
and adding them together
trivial way to get 0
non trivial way to get 0

linear independence means simply no redudency, every vector in your
set adds a genuinely new direction that cannot be built out of the others

linear independent means the only way to combine the vectors to get 0
is the boring trivial way.if you delete the vector from the set, you loose
the ability to reach certain places

linear dependent means atleast one vector in the set is redudent
it can be written as a linear combination of the others, so you can combine them with
non-zero weights and cancle them out
