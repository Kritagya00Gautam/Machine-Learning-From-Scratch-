# Machine Learning from Scratch

An introduction to machine learning and the ideas behind learning useful
patterns from data.

## What is machine learning?

Machine learning is the process of designing algorithms that can automatically
extract useful patterns from data. The emphasis is on **automatic**,
general-purpose methods: approaches that can be applied to many datasets to
produce meaningful results.

Three concepts are at the core of machine learning:

### Algorithms

Machine learning algorithms make predictions from input data or adapt a
model's parameters so that it performs well on data it has not seen before.

### Data

Data is what we use to discover valuable patterns and build models. It can
include observations, measurements, or examples relevant to the task.
For a computer to work with data, it must be represented numerically. A vector
can be viewed as an array of numbers, an arrow with direction and magnitude,
or an object that obeys addition and scaling.

### Models

A model is a design that learns from data to perform a task. A useful model
does more than fit the data it has seen: it should also generalize well to
unseen data. A model is a simplified representation of the unknown process
that generates real-world data, and can be used to make predictions without
running real-world experiments.

### Learning

Learning is the process of automatically finding patterns and structure in
data by optimizing a model's parameters. Many training methods can be thought
of as climbing a hill toward a peak; models are then evaluated on unseen data
to check how well they generalize.

## Foundations

The mathematical foundations used throughout machine learning include:

- Linear algebra and matrix decomposition
- Vector calculus and optimization
- Probability and distributions
- Analytic geometry

## Common tasks

Machine learning methods are used for regression, dimensionality reduction,
density estimation, and classification.
