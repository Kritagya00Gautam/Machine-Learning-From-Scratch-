# Machine Learning from Scratch

An introduction to machine learning and the ideas behind learning useful
patterns from data.

## What is machine learning?

Machine learning is the process of designing algorithms that can automatically
extract useful patterns from data. The emphasis is on **automatic**,
general-purpose methods: approaches that can be applied to many datasets to
produce meaningful results.

Three concepts are at the core of machine learning:

### Data

Data is what we use to discover valuable patterns and build models. It can
include observations, measurements, or examples relevant to the task.

### Models

A model is a design that learns from data to perform a task. A useful model
does more than fit the data it has seen: it should also generalize well to
unseen data.

### Learning

Learning is the process of automatically finding patterns and structure in
data by optimizing a model's parameters.
